Student Attendance Portal
A simple and interactive Student Attendance Portal built using HTML, CSS, JavaScript, and JSS for the Web Technology Laboratory project.

🚀 Features
Student registration form
Attendance marking
Responsive and attractive UI
Easy-to-use design
Stores attendance data temporarily in the browser
📁 Project Structure
Student Attendance Portal.html → Main project file
Includes HTML + CSS + JavaScript in one file
🛠 Technologies Used
HTML
CSS
JavaScript
JSS
📌 How to Run
Download or clone the repository:
https://github.com/Ratnamala-Munnoli/Student-Attendance-Portal
Open the project folder.
Run the .html file in any browser or open it using VS Code with Live Server.

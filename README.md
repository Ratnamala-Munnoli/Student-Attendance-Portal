# Student Attendance Portal

A simple and interactive **Student Attendance Portal** built using **HTML, CSS, JavaScript**, and **JSS** for the Web Technology Laboratory project.

## 🚀 Features
- Student registration form  
- Attendance marking  
- Responsive and attractive UI  
- Easy-to-use design  
- Stores attendance data temporarily in the browser  

## 📁 Project Structure
- **Student Attendance Portal.html** → Main project file  
- Includes HTML + CSS + JavaScript in one file  

## 🛠 Technologies Used
- HTML  
- CSS  
- JavaScript  
- JSS  

## 📌 How to Run
1. Download or clone the repository:
2. https://github.com/Ratnamala-Munnoli/Student-Attendance-Portal
3. 2. Open the project folder.
3. Run the `.html` file in any browser or open it using VS Code with Live Server.
